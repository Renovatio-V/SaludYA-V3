# SaludYa!

SaludYa! es una demo web para gestionar servicios de salud. Permite iniciar sesión y consultar o administrar citas, historial médico y datos del perfil.

## Secciones

- `index.html`: inicio de sesión.
- `pages/dashboard.html`: panel principal.
- `pages/citas.html`: gestión de citas.
- `pages/historial.html`: servicios completados y prescripciones.
- `pages/perfil.html`: datos personales y seguridad.

## Uso

Abre `index.html` en un navegador o publica el repositorio en GitHub Pages. Usa `juan.perez` y `saludya123` para entrar a la demo.

La aplicación está hecha con HTML, CSS y JavaScript, sin backend. Los datos de prueba se guardan en el almacenamiento local del navegador.
